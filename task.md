This repo uses typedoc to generate it's documentation from the Markdown files in this repo.
The documentation is published on https://comunica.github.io/traqula/
but the links to the inside of the repo do not always seem to work.
For example, the link to the SPARQL 1.1 parser resolves to: https://comunica.github.io/engines/parser-sparql-1-1 which is not a valid IRI.
Note that this link does correctly work when using the GitHub interface itself: https://github.com/comunica/traqula

Another case is for example a link to https://comunica.github.io/traqula/media/guidelines.md
which is just rendered as a plain text file without any Markdown rendering or typedoc templating.
